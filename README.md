# SANЯ CLIENT 0.0.6

Жартівливий клієнтський Fabric-мод для Minecraft 1.21.11.

## Функції

- Меню на **Right Shift**.
- Перемикачі HUD, клавіш, координат і CPS.
- FPS, координати, відображення WASD/стрибка та лічильник кліків за останню секунду.
- **Low Particles** перемикає частинки на мінімальний режим і відновлює попереднє значення при вимкненні.
- Анімоване меню з розділами огляду, HUD, візуалу, оптимізації та профілю.
- **Full Bright** (з Саня Visuals) накладає клієнтський ефект нічного бачення; перемикається в меню або клавішею **G**.
- **Echo Hands** додає легкий рух і пульсацію моделі руки від першої особи.
- Перемикач співвідношення сторін із чорними полями та індикатор прогресу КД предмета в руці.
- Візуальні індикатори броні, ефектів зілля та отримання удару.
- **Target HUD** показує здоров’я, броню та відстань до гравця, на якого наведено приціл.
- **Target ESP** перемикається в меню та показує фіолетові кутові мітки й пульсуюче кільце під гравцем, на якого наведено приціл і якого видно напряму; крізь стіни не підсвічує.

Меню використовує звичайний вбудований шрифт Minecraft. Мод не додає автоматичних PvP-дій і не змінює серверну поведінку.

## Збірка

Потрібен JDK 21. Щоб зібрати мод без термінала, двічі клацни `build-mod.bat` і дочекайся результату.

Готовий файл з'явиться у `build/libs/`. Щоб встановити мод, поклади jar до папки `mods` у профілі Fabric для Minecraft 1.21.11.

## Керування

- **Right Shift** — відкрити/закрити меню.
- **G** — Full Bright.
- У налаштуваннях керування клавішу можна перепризначити як **Open SANЯ menu**.
